# 200 人训练后注册：扩大样本与个人记忆消融

2026-09-09 冻结方案。协议：`post-enrollment-200-v1`。

## 要回答的问题

上一轮把 30 人完全排除在公共模型训练之外，再用各自的注册数据建立
个人 LoRA 和参考记忆，得到了初步改善。本轮扩大到 200 人，检查改善是否
仍然存在，并在同一批人、同一公共模型、相同标签预算下解释改善来自哪里。
本文件是训练前的计划，不代表训练已完成或某个模块已被证明有效。

本轮选择 200 人，不同时再训练一个 100 人版本；不增加随机种子、交叉验证、
新主干或新超参数搜索。所有候选在看本轮测试结果之前固定。

## 划分及可用标签

从原官方 CalBased 的 2,506 人中，按来源分别随机抽取 100 名 MIMIC、
100 名 VitalDB 受试者。种子 20260909；只读排序后的身份和来源信息进行抽样，
不使用血压、旧模型误差或逐搏质量来挑选人。记录与上一轮 30 人名单的交集，
不按旧结果重新抽样。

正式拟合前的内容审计发现：抽样中的 1 人与未抽样的另一个 MIMIC 编号共享
5 个完全相同的 PPG 内容哈希。首次预处理作业 1728 因此失败，未产生任何
正式模型或测试分数。修订规则为：保持随机选出的 200 人不变，将与其重复内容
相连的其他编号整人隔离出公共拟合及测试（含传递连接）。只使用身份和内容哈希，
不使用 BP 或模型误差。它不证明两个编号必定是同一真实人，但避免了潜在泄漏。
修订后的正式审计 1736 已确认额外 1 人，剩余公共队列为 2,305 人。
200 人自身不同编号之间无完全重复的 PPG 内容；其注册/测试内容重复数也为零。
剩余公共人群保留 34 条此前批准的官方源内训练/测试重复内容记录，并如实披露。

抽出的 200 人不得出现在公共模型的训练、内部验证、标签标准化、个人均值、
参数拟合或参考记忆中。公共模型从头训练，不使用以前已经接触过这些人的权重。
原始数据不移动、不删除；新划分由有哈希校验的清单表示。

每人内部的窗口归属保留官方 360/40 membership，因此这是从官方成员派生的
“整人排除后注册”实验，不是原封不动的官方 2,506 人复现实验。
原来批准保留的官方源内重复内容继续保留并披露数量；跨两个人群的内容或时间

## 训练及个人建档

1. 用剩余 2,305 人的 320/40 内部划分从头训练公共模型，连续 8 轮未改善停止，
   不设置 25 轮之类的总轮数上限。按内部验证选出的轮数，从头拟合其 360 个窗口。
2. 冻结该模型，在剩余人群原来的 40 个测试窗口上生成一次独立基准结果。
   该基准的测试分数不会改变下一步的个人训练设置。
3. 对每名新用户新建 rank-4 LoRA，只有 2,048 个个人参数可训练；公共编码器、
   回归头、归一化统计和其他用户档案全部冻结。用该人的 320/40 注册内划分选
   轮数，允许 0 轮胜出；再初始化个人参数，在全部 360 个注册窗口上重训这些轮数。
4. 从其注册数据构建个人参考库。先保存所有候选的测试预测和文件哈希，再允许
   评分程序读取这 40 个窗口的真实 BP。没有测试反馈优化、测试筛人或拒绝报告差的人。
5. 保存个人适配器、公共版本哈希、个人均值、标准化参数、原始/适配后特征库、
   注册标签和门控状态。每个人重新加载后必须复现全部候选预测。

公共主干沿用上一轮的 `resnet_small`，256 维特征；个人 LoRA 是特征空间的
rank-4 残差适配，不是 Transformer attention LoRA。优化设置不变：AdamW，
学习率 3e-4、weight decay 1e-4、batch 64、标准化 BP 上的 Huber delta 0.5。
个人训练复用冻结编码器的特征缓存，速度快不代表跳过优化。

## 九种配对结果：不是九次公共模型重训

| Setting | 实际做法 | 用于回答 |
|---|---|---|
| `personal_mean` | 始终输出个人注册 BP 均值 | 只记住这个人的平均血压够不够？ |
| `shared_with_anchor` | 公共 PPG 网络加个人均值，个人 LoRA 为零 | 不做个人神经参数适配会怎样？ |
| `new_person_lora` | 用注册数据训练个人 LoRA，不检索记忆 | 单 LoRA 基准 |
| `new_person_lora_memory` | 个人 LoRA 加相似度加权、距离门控参考记忆 | 当前完整候选；主要比较对象 |
| `shared_memory_only` | 无个人 LoRA，用冻结公共特征检索个人 BP 库，仅输出检索值 | 无 LoRA 的记忆本身是否足够？ |
| `shared_memory_blend` | 无个人 LoRA，公共预测与公共特征检索记忆按相同规则融合 | 固定公共模型下的 LoRA × 记忆配对对照 |
| `lora_memory_only` | 用个人 LoRA 特征检索，但只输出参考库结果，不混入回归预测 | 适配后的检索本身能否替代融合？ |
| `lora_memory_uniform` | 保留相同 top-5 和距离门控，将参考权重改成五个相等 | 相似度加权是否有用？ |
| `lora_memory_fixed_half` | 保留相同 top-5 和相似度权重，固定各占一半 | 距离门控是否有用？ |

所有记忆均仅检索该人合法注册窗口；保留原 top-5 余弦检索和温度 0.1。
距离阈值 q95 只从其注册库的 leave-40-block 邻居距离确定。等权对照不改变
top-5 的选择，只改变权重。没有五个合法参考时，融合候选退回各自基础预测；
仅记忆候选退回该人的注册 BP 均值。保留全部测试窗口并报告这种回退数量。

`shared_memory_only` 没有个人 LoRA，但仍然使用公共 PPG 编码器；
`lora_memory_only` 仍然依赖已训练的个人 LoRA，不能写成“去掉 LoRA”。
上述是同一冻结公共网络下的个人建档/预测组件消融，不是从零重训每种公共网络。

## 已有消融与本轮新增证据

- 旧已注册人群实验曾比较单参考、等权参考、相似度检索、距离融合，并进行了
  时间排除、最近时间参考等诊断。这些结果属于旧队列/协议。
- 最新 30 人注册实验只有个人均值、公共加均值、单 LoRA、LoRA＋记忆四组。
  它没有独立的无 LoRA memory-only、去门控和去相似度加权结果。
- 本轮补齐这些关键对照。旧协议上的消融不能替代此次新用户实验的消融。
  即使候选更好，也不能在缺少配对比较时断言模块必然具有不可替代的协同效应。

## 结果格式与不确定性

主要评价以受试者为单位计算 MAE，再对人取平均；同时报告每人的改善与恶化。
每个方法固定输出 Overall、MIMIC、VitalDB 三份结果。完整诊断表列为：
Setting、BP、MAE、R²、ME、STD、≤5 mmHg、≤10 mmHg、≤15 mmHg、AAMI、BHS。
AAMI/BHS 只是回顾性数值筛查，不是医疗器械认证或已经完成标准临床验证。

预先固定主要比较：完整候选减去单 LoRA 的 Overall 平均 SBP/DBP MAE；报告时
统一用“基准减候选”表示正值为改善。按受试者配对、来源分层 bootstrap 2,000 次，
种子 20260909，给出 95% 点区间。另报告两种 BP、两种来源及其他消融的探索性区间。
不将窗口当独立人数；不把这些区间当成随机训练种子的不确定性，不以多个点区间
宣称已完成多重比较校正。历史实验已接触过这个数据库，仍属于探索性验证。
