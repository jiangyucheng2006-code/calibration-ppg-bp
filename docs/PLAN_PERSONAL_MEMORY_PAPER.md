## 1. 结论与可发表的问题

建议保留 **Personal Memory–Augmented Blood Pressure Estimation from PPG in Registered Users**
这一方向，但把问题收窄为：

> 在相同个人训练标签预算下，显式保存的个人 PPG/BP 测量记录，能否补充已训练好的个人
> LoRA 参数？这种补充究竟依赖时间邻近，还是包含与当前 PPG 状态相关的额外信息？

当前支持“已注册用户的部分预测可以改善”，尚不支持“新的关系网络已稳定超过 LoRA”。
论文贡献应当来自可复现的机制和适用条件，而不是给已有 LoRA、kNN 或残差修正换名字。
更低的平均 MAE 是重要证据，但不是唯一的发表条件，也不能替代合理对照和最终验证。

## 2. 已有证据、假设与不足

| 项目 | 已知事实 | 允许的解释 / 待检验问题 |
|---|---|---|
| 随机划分 | 最佳融合 mean MAE 2.6475，续训 LoRA 2.8764；融合 best epoch=0 | 固定检索与融合有增量；不能归功于新关系网络训练 |
| 时间划分 | 最佳融合 3.6571，配对 LoRA 约 3.7124；best epoch=1 | 小幅增量；自身初始化 3.7967，因此确有训练增量，但尚无独立种子确认 |
| 时间近邻 | 随机划分 D3 最近时间 train BP 为 2.2851，优于融合 | 当前融合并非优于所有简单参考；时间信息是强竞争解释 |
| 时间间隔 | D1 特征检索从 2.6973 变成 60s 排除后的 3.1590 | 提示邻近性依赖；尚未对完整融合进行这项检查 |
| 训练任务 | train query 排除整块 40 窗口，validation 不采用同样的整块排除 | 可能存在参考距离/可用数量分布失配，未证明它是失败原因 |
| 个人化基础 | 原有 LoRA 与个人状态保持不变 | 新模块应与强 LoRA 和 epoch-0 固定融合分别比较 |

“0.15 mmHg、两种划分均提升”是本项目预先写定的模型升级规则，不是通用发表标准。
v1 不通过该规则，不能事后更改结论；其观察仍可作为后续研究的动机。

## 3. 先做一组能够决定方向的冻结诊断

无需重新训练主干，使用同一批已冻结模型和相同完整查询队列。

**比较方法：** 配对强 LoRA、epoch-0 固定融合、训练后融合、特征 kNN、最近时间 BP，
以及在相同时间距离层内随机选择历史参考的对照。时间最近的参考只能来自当前协议允许
的 train 角色；时间划分必须是同一可比较记录时钟上的过去参考。

**条件：** 既定 0s 与 60s 额外排除带；另预先列出 300s 作为新增探索性压力测试，
不把它伪称 v1 预注册分析。随机划分补充“仅过去 train 参考”，明确它不是原主表。
0s 仍须排除自引用、重叠生理区间和重复内容，不是允许相同片段。

**关键控制：** 在 train 内固定时间距离分层，再在同层比较按 PPG 相似性检索与随机检索。
不能把极近的时间参考与很远的波形参考比较后，就宣称某一种信息没有用。
某一层没有足够参考时回退 LoRA，并报告比例；所有查询和人都保留。

**新增输出：** 每种方法/条件的 Overall、MIMIC、VitalDB 全表；参考距离、回退率；相对
个人训练 BP 中位数变化 0–10/10–20/>20 mmHg 的评分分组；分组边界不从最终测试选择。
真实 query BP 只可用于最后评分分组，不能用于检索、门控或选择“好样本”。

**决策：** 若完整融合在时间匹配对照和合理间隔后仍有增量，继续下述神经训练；若优势
仅限随机近邻插值，应收窄论文主张，或优先考虑最后的机制论文备选路线。

## 4. 最小神经改进矩阵：每次回答一个问题

这些是待验证方案，不是已产生好结果的模型。不直接把所有改动一次叠加。

| 编号 | 主要改变 | 解决的具体问题 | 必须比较 / 停止条件 |
|---|---|---|---|
| E1 | 检索情境匹配的成对训练 | 训练时参考很远、预测时参考很近，学到的修正可能不匹配 | 比旧训练与 epoch-0 固定融合；训练后仍不及固定融合则停止继续加深关系网络 |
| E2 | 专门为同人 BP 状态学习检索度量 | 原有 256D 预测特征的余弦相似性，不一定代表参考 BP 对当前估计有帮助 | 在同一固定融合下，只换检索度量；保持 m=5、原库、标签和融合规则不变 |
| E3 | 可靠性约束的记忆融合 | 近邻波形相似但参考间不一致时，固定距离权重可能过度相信记忆 | 比固定权重；检查大 BP 变化处是否被错误压回均值，不允许删除困难查询 |

### E1：训练时模拟实际可获得的历史，不通过放松评估获得提升

先测量 v1 train/validation 的参考数量、时间间隔和特征距离分布，确认是否真有失配。
新增训练 episode 只在原 train 内划分 pseudo-query 与 memory。分别模拟随机插值与过去
历史两种情境，并覆盖近、中、远参考；分层/采样规则用 train 内部资料确定。
保留原评估划分、全局 ID/hash/重叠检查、时间先后和每人 320 标签预算。

若需将 train 的“40 窗口整块排除”改成显式时间间隔约束，应作为独立 v2 训练策略写入
配置和测试，经批准后实施；不能静默关掉 v1 保护。外层验证/held-out 规则不随之改变。
先保留原网络、优化器和损失，隔离采样因素；不能同一次又改网络、损失和检索。

### E2：学习“对血压预测有用的相似”，而不只是“看起来相似”

冻结 LoRA，从其特征学习一个小型检索投影，例如 256→32 维。利用 **train 内同一个人**
的 BP 差监督：相近 BP 状态靠近；对“原特征很像但 BP 差很大”的训练对加强区分。
控制同人/时间距离采样，避免模型只学到身份或时间邻近代理。SBP/DBP 差按 train 尺度
标准化；不能用 validation BP 给近邻排序或选阈值。

先仅更换检索空间，仍使用原来的固定融合和 m=5。为保持单变量，第一项比较固定每个
query 在原 256D 空间计算的 alpha，只更换参考选择/加权；也单独报告 memory-only。
若按新空间距离重算 q95/alpha，须另列为后续组合，不称为只换检索。
投影/其尺度只在 train 拟合，
所有记忆特征由同一个冻结版本编码。若以后压缩存储，必须真正不再保存原 256D 库才
能声称节约空间；保留两套库不能把 32D 当作总存储成本。
这属于监督度量学习的应用与改进，不声称“度量学习”本身新颖。

### E3：先验证可观测可靠性，再考虑学习门控

当前形式是 `prediction = LoRA + alpha * (memory_prediction - LoRA)`。
可检验的增强是让 alpha 同时考虑 PPG 距离、有效参考数量、参考预测的分散程度，以及
两种预测的分歧。时间间隔只有在可比较时钟和拟部署数据可得时才使用；否则只做诊断。
参考间不一致可能代表真实血压动态，而非噪声，因此必须检查变化较大分组，不能直接
规定“分歧大就信 LoRA”并把它当成可靠性真值。

若训练一个预测哪条分支更准的门控，需要 **编码器级交叉拟合**：共享主干、LoRA、
个人锚点、scaler 和参考库都不能见过内层 query 的标签，初始 checkpoint 也不能已受
这些标签监督。仅从 bank 删除 query 并不是 OOF。各折独立编码/检索，不混合坐标空间。
如采用 E2 监督投影或已训练的成对关系网络，这些组件及其 checkpoint/超参数选择同样
必须排除内层 query 标签。上游 early stopping 使用内层训练中再划出的验证部分，不能
用拟供门控学习的 OOF query 标签选择上游 checkpoint。
内层较少标签模型与最终 320 标签模型的误差分布差异须另查；不满足则保留简单固定门控。
这一步计算更贵，放在 E1/E2 或冻结诊断显示确有可利用的互补信息之后。

## 5. 明确不重复的捷径与失败处理

- 不把 `LoRA(q)-LoRA(r)` 包装成新关系模型：代回公式后只是加权残差修正。
- 不用完整训练集上的极小拟合残差冒充未见误差来训练门控。
- 不继续扩大 Transformer/ResNet 或盲目扫几十种 kernel；它们没有针对当前反证。
- 不通过移除最差 30%、近时间外的困难 query、或缩小评价队列来改善主表。
- 如果 E1 失败而固定融合仍好，可放弃关系网络；简单方法也可贡献可复现的研究发现。
- 如果 E2 在控制时间后仍不能改善检索，不能强讲“PPG 状态检索更好”的故事。
- 如果只在随机模式好，明确为已注册用户的插值用途，不改写为长期连续追踪。

## 6. 从候选到论文需要补齐什么

1. **有限开发阶段：** 先冻结诊断，再至多三类针对性变更；单种子筛选，每个候选与同起点
   LoRA、固定融合配对。保留最佳 epoch0/训练后结果、优化步数、真实训练时间。
2. **候选确认：** 选定后固定三枚新随机种子，例如 20260911/20260912/20260913。
   若主张端到端稳定性，应重训主干/个人 LoRA，而不只改变小模块初始化；后者只能声称
   条件于同一冻结主干的稳定性。多次筛选过的开发集不是独立确认集。
3. **机制消融：** LoRA 单独、memory 单独、固定融合、提出的单改进/完整方法；去掉检索
   学习或门控分别比较。加入时间匹配随机参考；冻结模型输入扰动与从头训练消融分开。
4. **统计：** 同一受试者的模型差值做配对、按来源分层的受试者 bootstrap，报告 95% CI；
   不把 82,040 个窗口当独立样本。固定主比较，对探索性多比较作限定，CI 不消除选择偏差。
5. **最终封存验证：** 在模型/阈值/所有排除规则锁定并获授权后，才使用已保留的 held-out
   窗口。先核对其未被旧脚本读取及精确内容分离；不能为核对而先查看其结果。测试后不
   再按该测试结果调参。此仍是 registered-user 同源验证，不是新用户或外部验证。
6. **资源和实际用途：** 计入原 LoRA、每人全部记忆、检索延迟、CPU/GPU计时、模型选择成本。
   时间长跨度/独立记录不足则明确缺失，不虚构长期稳定性。压力/运动/跨设备须另有可信
   条件标注和合法校准的独立数据；不以 MIMIC/VitalDB 内部分层代替外部验证。

晋级目标继续沿用 v1：两种模式 Overall mean MAE 各降低至少 0.15 mmHg，且两来源均正向。
达到它也不自动证明临床效用或可发表；未达到它也不自动否定机制/效率研究。

## 7. 论文主线与备选

**方法论文候选题目：** Personal Memory–Augmented Blood Pressure Estimation from PPG in Registered Users.

可成立的贡献必须分别获得证据：(i) 参数化个人记忆与测量记忆的互补；(ii) 检索情境匹配或
BP 状态感知的具体改进；(iii) 超越固定融合及合法时间对照，并交代在时间间隔、血压变化
和两个来源上的适用边界。核心方法可保持简洁；不能隐去 LoRA 的引用与原始构件来源。

文章顺序：问题与最近邻文献 → 明确已注册用户/320 标签预算 → 方法和角色契约 → 两种划分
主结果 → 时间/波形信息对照与消融 → 封存确认和资源成本 → 局限性。
正文保留 4 组关键表图；历史几十轮探索与失败记录放补充材料，不删除失败实验。

**如方法增量始终局限于近邻插值：** 改为机制/评测研究，例如
*When Does Personal Measurement Memory Help PPG-Based Blood Pressure Estimation?*
需要证明并量化“何时有用、何时失效”，而不是只报告负结果；不能保证这种题目会被录用。
目标期刊及所需外部/前瞻证据应在这些结果明确后再定，不以先编一个故事替代实证。
